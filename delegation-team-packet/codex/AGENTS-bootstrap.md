## Delegation (shared rulebook)

Before nontrivial work (analysis, implementation, review, or handing work to helpers), read these
two files in order:

1. `{{SHARED_ROOT}}/POLICY.md`
2. `{{SHARED_ROOT}}/profiles/{{PROFILE}}.md`

If either file is missing or unreadable, say so and do not delegate from memory. The rulebook
defines routes, models, effort levels and safety limits. Use only the routes the profile lists,
in the rulebook's cheapest-first order. Claude helpers may be used only where the profile lists
Claude Code and those helper routes; otherwise use the available relays or your own tools.
Every tool uses its subscription login. API keys are banned: do not set, store or ask for one.

The rulebook, profile, helper definitions, lane file, consensus skills and this section are owned
by the packet installer. Do not edit them; ask the packet owner for a newer packet and run its
installer again.

In server mode, follow "Desktop mode and server mode" in `POLICY.md` wherever these instructions say to ask a person.
